# Licence Plate Game for iPhone
_Catchy name TBD_

## Introduction
I enjoy playing the license plate game on long trips, but I have found that the most downloaded options use just state plates and not necessarily the different versions of the plates within each state. Given that Florida has _many_ options, this is a side-project to create an iPhone app to turn all of the license plate options in Florida into a checklist.

## Why Florida?
Well, that's where I currently reside. Once I get a handle on Florida, I may explore adding other states.

## Ideas
- Store coordinates of where a plate was found
  - May be tricky to do if Internet connection is not available when marking off the plate
- When other states are added, add a distance of some sort for indicating how far away you have found states
  - Allows this to turn into a longer game as you may find a plate further away at any given point to increase your distance score
  - e.g. No distance points for finding a Florida plate in Florida. Once I drive into Georgia, I can nab bonus points for finding a Florida plate
